# Code of conduct

Grok Box is a small community project. We want it to be a friendly place for everyone who uses or
improves it.

**Please do**
- Be respectful and patient. People here have different backgrounds, languages and experience.
- Assume good faith. Ask before you judge.
- Keep feedback about the work, not the person.

**Please don't**
- Harass, insult or threaten anyone, in public or in private messages.
- Share other people's private data: not in issues, comments, logs, screenshots or fixtures. This
  includes e-mail addresses, ids, host names and conversation text from someone else's box.
- Post spam or off-topic advertising.

**What maintainers may do**
Maintainers may edit, hide or remove comments, issues and pull requests, and may block people from
the repository when this code is not followed.

**Reporting**
To report a conduct problem, use GitHub's **Report content** option on the comment or issue, or
contact the maintainer through their GitHub profile. Please do not use the security advisory form for
conduct reports; it is meant for vulnerabilities.
